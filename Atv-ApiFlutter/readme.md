## Sobre o projeto

Este projeto é uma aplicação desenvolvida em Flutter para consulta de voos a partir de uma API externa.

A aplicação permite buscar voos por aeroporto utilizando o código ICAO, filtrar os resultados entre chegadas, partidas ou todos os voos e visualizar informações detalhadas de cada voo selecionado.

O projeto foi desenvolvido com foco em integração com API, gerenciamento de estado com Provider, navegação entre telas e construção de interfaces dinâmicas a partir dos dados retornados pela API.

### Principais funcionalidades

- Busca de voos por código ICAO do aeroporto
- Filtro entre chegadas, partidas e todos os voos
- Listagem dinâmica dos voos encontrados
- Tela de detalhes para cada voo
- Exibição de informações como identificação, origem/destino, horários e tipo da aeronave
- Feedback visual durante o carregamento dos dados
- Gerenciamento de estado utilizando Provider

### Tecnologias utilizadas

- Flutter
- Dart
- Provider
- HTTP
- API REST
